# LootPilot v0.10.7

![LootPilot Logo](assets/LootPilot-logo.png)

LootPilot 是 ShadePilot 系列的《逃离塔科夫》屏幕物资识别与价格悬浮工具，支持 Windows 10/11。

程序只处理屏幕上已经显示的像素：不读取游戏内存、不注入 DLL、不 Hook 游戏、不解析封包，也不模拟鼠标键盘操作。此路线仍不代表 BSG 或 BattlEye 的官方安全保证。

## v0.10.7 分区网格与整屏漏标修正

- 胸挂、口袋、特殊装备栏、安全箱、已装备胸挂和已装备背包恢复独立网格，不再共用会累积误差的统一 `8×13` 网格。
- OCR 名称右边缘增加 4 个原图像素的格线容差，避免压线文字被分到右侧相邻格。
- 支持把同一 OCR 长块中的重复物品名称拆成独立子块，例如连续三支 `6L23` 均可单独标价。
- 多格物品旋转优先比较内部格线强度，修复 Vudu `2×1` 被错误横放的问题。
- 物品名称所在格允许邻近占用格验证，避免多格物品名称落在低纹理格时被整屏扫描过滤。
- 小型分区保持 OCR 输入坐标不缩放；大型仓库仍使用限幅检测，兼顾定位和速度。

## v0.10.6 价格框格子对齐

- 价格框会测量自身一行或两行的实际高度，使底边准确贴近物品格子的左下角。
- 多格物品根据 OCR 名称右边缘、物品占格尺寸和可见边框反推完整外框，并支持旋转方向判断。
- 已装备胸挂和背包按画面中的固定 `2×2` 装备槽定位；口袋和特殊装备栏按单格显示槽定位。
- 同一多格物品被 OCR 重复读取时，会按重叠范围保留置信度最高的一条价格框。

## v0.10.5 整屏中文识别与扫描估值

- 整屏扫描同步启用 PP-OCRv6 中文识别，并保留 Tesseract 并行候选与自动降级。
- 扫描完成后在游戏画面右上方显示识别数量、最佳总价值、跳蚤合计和商人合计。
- “最佳总价值”逐件取跳蚤价和商人价中的较高值；统计仅覆盖本次可靠识别到的物品。

## v0.10.4 小号中文识别增强

- 单物品扫描新增离线 PP-OCRv6 中文识别通道，针对游戏界面中的小号、描边和复杂背景中文。
- 新通道与原有 Tesseract 并行运行并合并候选；神经网络模型不可用时会自动退回原有识别流程。
- v0.10.4 测试阶段整屏批量扫描仍使用 Tesseract；v0.10.5 起已同步启用新模型。
- 可在 `appsettings.json` 或用户设置中将 `UseNeuralChineseOcr` 设为 `false`，快速关闭新通道。

## v0.10.3 鼠标定位与中文细字修正

- 单物品首轮裁剪从过宽的 `480×140` 收紧为以鼠标为中心的 `240×180`，避免把左侧相邻物品名称一起纳入候选。
- 默认自动模式只处理鼠标附近，不再无条件扫描屏幕中央固定区域；检查窗口专用区域仍可通过配置启用。
- 鼠标模式增加 105 像素硬距离限制，并显著提高位置权重；宁可不给结果，也不再用远处完整英文名顶替目标。
- 中文首选图像改为保留原色细笔画的高质量放大；低可信回退仍会尝试灰度和阈值版本。

## v0.10.2 快捷键、窗口与 LOGO 修正

- 修复旧设置中的裸数字 `8`、`9` 被当成主键盘数字的问题：现在会自动迁移为 `NumPad8`、`NumPad9`。
- 在快捷键输入框内直接按下想使用的组合键即可录入，支持小键盘单键；小键盘数字需要开启 NumLock。
- 快捷键注册失败不再中断价格缓存初始化，状态区会给出冲突提示；注册过程也增加了键盘驱动兼容回退。
- 设置区支持垂直滚动，非全屏窗口也能找到“保存并应用”。
- LOGO 与程序图标保留原设计并改为透明背景。

## 快捷扫描

- 单物品快捷键默认 `Alt+Q`：识别鼠标附近或检查窗口中的物品。
- 整屏快捷键默认 `Alt+W`：扫描仓库、右侧容器以及从弹挂到背包/口袋/安全箱的完整随身区域。
- 按下快捷键后，口袋右侧会立即出现“正在扫描…”反馈。
- 批量标价只在物品左下角显示两行小字：紫色“跳蚤价”和金色“最高商人价”，不重复显示物品名称。

## v0.10.1 中文、价格匹配与小键盘修正

- 单物品极速/平衡首轮改用 480×140 鼠标紧凑裁剪，不再处理完整 900×220 大图。
- 极速整屏使用原图倍率和单次中英 OCR，与平衡/并行产生明显性能差异；作为代价，中文小字漏识会更多。
- 基于当前 PvP/PvE 本地物品库自动生成 Tesseract 用户词表，增加塔科夫中文物品词汇提示。
- 中文两三字简称仍可完整匹配；英文三字符片段不再从杂乱 OCR 串中做包含命中，并增加模糊候选差值检查。
- 整屏英文模糊标注提高最低可信度，可疑项目优先不标，而不是显示错误价格。
- 快捷键改为自主解析，支持无修饰键的 `NumPad0`–`NumPad9`、`Num0`–`Num9`、“小键盘1”以及 `Add/Subtract/Multiply/Divide/Decimal`。

## v0.10.0 识别性能档位

- 设置页可在“极速 / 平衡 / 并行”三档之间自由切换，默认使用平衡模式。
- 极速：只处理主要鼠标区域、一张增强图和一次中英 OCR，占用最低。
- 平衡：先快速识别，单物品低可信或整屏区域无结果时自动启动精确回退。
- 并行：同时运行多区域、多增强图和双语言顺序 OCR，等待更短，但瞬时 CPU 占用更高。
- 每次单物品和整屏扫描完成后都会显示本次实际用时，方便比较三档表现。
- 七张回归截图中，并行整屏测试保持相同识别结果，总处理时间比极速串行约低 25%；实际游戏用时会受 CPU 和当前画面影响。

## v0.9.2 界面与价格显示

- 所有物价、每格价值、整屏合计和历史记录统一使用“万”为单位，例如 `12.6万` 和 `0.2万`。
- 单物品卡片改为塔科夫风格：深灰黑情报面板、卡其金状态条、方角描边和紧凑双栏价格。
- 整屏价格角标和扫描反馈也统一为同一套游戏内视觉，不再跟随主窗口主题变色。

## v0.9.1 修正

- 单物品识别改为优先匹配“按下快捷键瞬间”鼠标附近的 OCR 文字，不再从大范围截图中挑选距离很远的物品名。
- 整屏扫描会先检测右侧仓库/容器网格的实际纵坐标，再同步校正弹挂、口袋、背包和安全箱的识别区域。
- 新一次扫描前会清除旧价格层，且会在完成截图后才显示“正在扫描”反馈，避免软件把自己的物品名、商人名和价格再次识别。
- 修复 OCR 期间移动鼠标会改变匹配目标的问题。

## v0.9.0 新增

- 价值过滤器：可设置最低显示价值，低于阈值的物品不再显示角标；输入 `0` 表示全部显示。
- 扫描总价报告：每次整屏扫描显示识别数量、跳蚤合计和最高商人回收合计。
- 扫描记录：保存最近 50 次报告，包含时间、PvP/PvE、数量及两种总价；记录只存放在本机。

## v0.8.0 功能

- 中英文双 OCR 通道：同时运行 `chi_sim+eng` 与 `eng+chi_sim`，提高中文小字识别率。
- OCR 默认放大倍数提高到 3；旧配置会自动迁移。
- 随身物品区改为大范围覆盖，包含弹挂最左列、口袋、不同宽度背包和安全箱。
- 主界面重新设计为 ShadePilot 同系列卡片式 UI。
- 五套 ShadePilot 同源主题，可即时切换并自动保存：
  - 雾紫
  - 极夜蓝
  - 薄荷灰
  - 暖砂
  - 黑白极简
- 可在界面中切换 PvP / PvE 物价；两种模式使用独立本地缓存。
- 可自定义单物品与整屏快捷键，保存后立即重新注册。
- 快捷键占用或格式错误时恢复原设置，不会留下失效快捷键。

## 运行和测试

1. 解压完整发布包。
2. 运行 `LootPilot.exe`。
3. 等待状态显示“已就绪”。接口不可用但存在对应模式缓存时，程序会离线运行。
4. 在设置区选择 PvP/PvE、主题和两个快捷键，点击“保存并应用”。
5. 打开游戏仓库或容器并按整屏快捷键。

建议使用 1920×1080、无边框窗口或窗口化全屏。当前容器区域以这一分辨率的游戏 UI 为主要标定样本。

## 价格刷新

- 启动时刷新一次。
- 默认每 60 分钟自动刷新。
- 可随时点击“刷新物价”。
- 优先使用 eftarkov 中文物价数据，失败时回退到 tarkov.dev，再失败则使用当前 PvP/PvE 模式的本地缓存。

用户设置保存在：

```text
%LOCALAPPDATA%\LootPilot\settings.json
```

价格缓存按模式分开保存为 `items-pvp.json` 和 `items-pve.json`。

## 构建

需要 .NET 8 SDK：

```powershell
.\scripts\build.ps1
.\scripts\run.ps1
.\scripts\publish.ps1
```

完整发布包已内置 Tesseract、英文模型和简体中文模型，最终用户不需要单独安装 OCR。

## 当前限制

- 批量扫描仍主要依靠画面中可见的物品名称，不是完整图标分类器。
- 名称被遮挡、字体过小或画面压缩严重时会漏标；低可信结果会主动留空。
- 尚未根据堆叠数量、耐久度、旋转方向或武器改装状态修正价格。
- 非 1920×1080 或特殊 UI 缩放仍需要更多实图继续标定。
